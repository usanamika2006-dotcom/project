Memzo

Memzo – A Smart Subscription Management Platform

Memzo is a web-based subscription management platform designed to help users manage and track their subscriptions in one place.

Features

- User Registration and Login
- Secure Authentication
- Subscription Management
- Track Subscription Details
- Staff Management
- User-Friendly Interface

Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- HTML
- CSS
- JavaScript
- SQLite

Installation and Setup

1. Clone the repository:

git clone https://github.com/usanamika2006-dotcom/Memzo.git

2. Navigate to the project folder:

cd Memzo

3. Install the required dependencies:

pip install -r requirements.txt

4. Run the application:

python app.py

5. Open your browser and visit:

http://127.0.0.1:5000/

Project Purpose

The main goal of Memzo is to provide a simple and convenient way to organize and manage subscription-related information through a web-based platform.
